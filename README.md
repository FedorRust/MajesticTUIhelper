# mj

Памятка по законке Majestic RP в терминале. Поиск работает без интернета: тексты уже лежат в папке `laws`.

Неофициальная программа. Законка взята с форума Majestic RP.

## Скачать

Открой [последний выпуск](https://github.com/FedorRust/MajesticTUIhelper/releases/latest) и скачай один архив:

| Система | Файл |
| --- | --- |
| Windows 10 или 11 | `mj-windows.zip` |
| Linux | `mj-linux.zip` |

Распакуй архив. Внутри папка `mj`: программа и тексты законов рядом. Папку `laws` не отделяй от программы, иначе поиск ничего не найдёт.

**Windows.** Дважды щёлкни `mj.exe`. Откроется окно терминала.

**Linux.** В терминале:

```bash
cd mj
./mj
```

Если система не даёт запустить файл, один раз выполни `chmod +x mj`.

На Linux копирование в буфер на Wayland использует `wl-copy`. Если строка не вставляется, поставь пакет `wl-clipboard`.

## Как пользоваться

1. Выбери сервер: Portland или Memphis. Enter открывает поиск.
2. Введи номер статьи (`17`, `10.5ук`) или слова из названия (`угон`).
3. Enter открывает карточку: состав и наказание. Ещё раз Enter или `f` показывает полный текст.

| Клавиша | Действие |
| --- | --- |
| ↑ ↓ | Сервер, статья в списке или часть статьи |
| Enter | Открыть |
| f | Полный текст или обратно к карточке |
| c | Скопировать короткую строку |
| C | Скопировать статью целиком |
| Esc | Назад |
| F5 | Обновить тексты с форума |
| q | Выйти с экрана выбора сервера |
| t | Список тем на экране выбора сервера. Схема запоминается |
| F6 | Тот же список тем с экрана поиска |

Мышью можно нажимать те же пункты. На экране выбора сервера клик по знаку GitHub справа снизу открывает [github.com/FedorRust](https://github.com/FedorRust).

В поиске четыре кодекса выбранного сервера: УК, КоАП, ДК и УПК.

Обновление с форума просит логин XenForo. Пароль на диск не пишется. Сессия остаётся в папке настроек (`~/.config/mj` на Linux, `%APPDATA%\mj` на Windows).

## Сборка самому

Нужен [Rust](https://rustup.rs/).

```bash
cargo run --release
```

Программа ищет `laws` рядом с собой, в текущей папке или в каталоге из переменной `MJ_LAWS`.
